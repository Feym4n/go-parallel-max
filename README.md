# Поиск максимума в большом слайсе

Консольная программа на Go для сравнения последовательного и параллельного поиска максимального элемента.

Приложение создаёт слайс случайных положительных целых чисел, а затем находит максимум обычным перебором и обработкой восьми частей в отдельных горутинах. Для обоих вариантов выводятся найденное значение и время поиска в микросекундах.

Учебная работа по многопоточности в Go: запуск горутин, ожидание их завершения через `sync.WaitGroup` и обработка граничных случаев.

## Установка и запуск

1. Установите [Go](https://go.dev/dl/) версии 1.24.1 или новее.
2. Скачайте репозиторий и переключитесь на ветку с решением:

   ```bash
   git clone https://github.com/Feym4n/go-parallel-max.git
   cd go-parallel-max
   git switch first-iteration
   ```

3. Запустите программу из каталога проекта:

   ```bash
   go run .
   ```
